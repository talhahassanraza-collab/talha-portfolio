# Talha Hassan Raza — Portfolio

A responsive, static portfolio website built with HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in a browser, or run a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The contact form opens the visitor’s email application; it does not send or store
messages on a server. The background video can be changed from the settings
button.

## Template credit

The starting layout is based on the Drake HTML/CSS portfolio template by
IssaKass. Its original layout and supporting template assets remain part of the
provided source template.
